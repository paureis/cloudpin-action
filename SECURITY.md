# Security policy

This action is a thin wrapper around [cloudpin](https://github.com/paureis/cloudpin) and follows
[cloudpin's security policy](https://github.com/paureis/cloudpin/blob/main/SECURITY.md). Please report a security
problem in either one privately, through
[GitHub's private vulnerability reporting](https://github.com/paureis/cloudpin-action/security/advisories/new) on
this repository or [on cloudpin's](https://github.com/paureis/cloudpin/security/advisories/new), rather than in a
public issue. Examples for this action: a way for a mismatch, or a result it can't read, to leave the job green; the
action printing a token or credential value; or input that runs as code in its steps.
